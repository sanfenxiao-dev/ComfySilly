# ComfySilly · 故事工作室

一个 Rust / Tauri 2 + React / TypeScript 编写的 Windows 桌面角色对话工作室，以节点画布编辑 SillyTavern 预设，集中管理角色卡、世界书、交互前端和独立的对话记忆。

**当前版本：0.4.3 · Windows x64。** 这是早期公开版本，仍有插件兼容边界，不是 SillyTavern 的完全替代品。

0.4.3：支持正则按节点导入、多个 JSON 文件队列排序、正则连线参与实际执行顺序；聊天顶部工具栏可收起，并优化大型预设拖动时的序列化开销。包含 0.4.2 节点删除、撤销与画布保存修复。

## 下载与开始

在本仓库 **Releases** 页面选择 `v0.4.3`，下载安装程序 `ComfySilly_0.4.3_x64-setup.exe`，或直接运行 `ComfySilly.exe`；另提供 MSI 和 SHA-256 校验清单。运行不需要 Node、Rust、开发服务器或独立浏览器窗口，需要 Windows WebView2 Runtime。

1. 在「设置 → 模型与连接」配置 URL、Key、协议和模型，保存。
2. 在预设、角色书架、世界书栏目使用导入按钮选择文件；角色书本进入详情后可开始新对话或继续历史。
3. 顶栏头像可设用户身份；对话顶部可确认/切换当前预设。
4. 按需启用「设置 → 自动记忆」；默认关闭，启用会产生额外 LLM 请求费用。

应用尚未做代码签名，Windows 可能显示未知发布者提示；请确认下载来源。没有自动升级器。升级前关闭旧实例，并备份 `%APPDATA%/ComfySilly`。新版本沿用相同数据目录，不自动导入下载目录里的文件。

## 主要功能

- **预设画布**：导入/保存/切换 SillyTavern 预设、条目排序与开关、浮动编辑器、显示正则编辑；保留未知字段不等于执行所有插件语义。
- **角色与世界书**：PNG 角色卡导入、书架、角色详情、角色专属与全局世界书编辑及开关。
- **对话与分支**：历史修改、重新生成、回复变体、独立分支、历史搜索与删除、Markdown/JSON 导出。
- **交互卡前端**：聊天内沙盒 HTML 与部分酒馆助手变量/消息/事件 API；脚本需要按卡信任授权。不是通用任意插件执行环境。
- **自动记忆**：只用 LLM，不需要 embedding 或向量数据库。角色、会话、分支各自隔离；可查看来源、修正、暂停与重建。
- **阅读偏好**：居中/气泡/紧凑排版，主题与动效、用户头像、发送快捷键；可配置默认显示最近消息数量。

### 显示条数 ≠ 模型读取条数

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| 对话偏好 → 默认显示最近消息数 | 只限制界面渲染，可加载或收起更早消息；不删除、不截断模型历史 | 80 条，范围 10–500 |
| 自动记忆 → 保留最近消息数 | 启用记忆时至少发送的近期原文；已整理的旧消息由记忆替代，未整理的仍保留 | 12 条，范围 6–200 |

用户或 AI 的一次发言各算一条，不是一轮。模型实际读取还受预设预算、记忆整理进度和提供商上下文能力影响；不是无限读取。记忆开启时不会为了适配预算静默删除未整理历史，超限会提示；关闭时会按预设预算裁剪较早历史并提示。本地完整原文均保留。

## 安全与兼容边界

- API Key 在 Windows 使用 DPAPI 加密，绑定当前 Windows 用户；不要上传数据目录、密钥、私聊或日志中的敏感内容。
- **仅信任可靠来源的角色脚本**。授权后可读取当前对话/变量、访问网络并请求模型，可能产生费用；不直接获得 API Key 或桌面文件权限。不要把沙盒当成可以安全运行任意恶意代码的保证。
- EJS 提示词模板、任意酒馆 DOM 插件、QuickReply、TTS、生图与通用 DAG 执行器尚未完整实现；部分世界书扫描策略有边界。详见 `web/README.md`。
- 自动记忆是有损摘要，不保证完美回忆；只处理当前打开的会话，不在退出后运行。远程卡片资源需要可访问的网络。
- 本次回归使用测试夹具和本地模拟服务，未自动调用真实付费模型，未逐一卡片验证第三方插件。

## 开发

建议 Windows x64、Node.js 24、pnpm 11、Rust 1.90+ / MSVC 与 Windows SDK。

```powershell
cd web
pnpm install --frozen-lockfile
pnpm exec tauri dev

# 检查与构建
pnpm test
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml --lib
pnpm exec tauri build
```

UI 回归需要 Edge 与 Playwright，详见 `web/README.md`；测试夹具不进入生产包。
