# ComfySilly 0.4.1 — 显示窗口与上下文分离

## 新增与调整

- 「设置 → 对话偏好 → 默认显示最近消息数」：默认 80 条，支持 10–500 条。用户或 AI 每次发言各算一条，不是一轮。
- 仅界面隐藏较早消息，不删除本地历史，不据此裁剪模型输入、脚本历史、世界书扫描或自动记忆来源。
- 顶部可每次加载 40 条旧消息，保持滚动阅读锚点；加载后可收起，恢复设置中的显示范围。切换会话或更改设置会恢复默认范围。
- 自动记忆的近期原文窗口可设 6–200 条（默认 12）。这是模型至少读取的近期原文，不是硬性上限；只替代已整理的旧历史，未整理的消息仍保留。
- 「对话偏好」解释显示窗口与模型窗口的区别，并可跳转到记忆设置；不新增与现有逻辑冲突的硬截断控制。
- 修正上下文预算错误提示，不再指向已移除的聊天「生成参数」按钮。
- 更新窗口标题、关于、软件包版本和安装包为 0.4.1。加入根目录使用说明、安全说明和 Windows 源码 CI。

## 继承 0.4.0 自动记忆

只用已配置的 LLM，支持独立记忆连接，不使用 embedding 或向量数据库。每个角色的每个会话独立保存；分支只继承分叉点之前有效的记忆，编辑/切换回复变体会使覆盖不符的摘要失效。后台整理优先让路给正常生成。可查看来源、修正、暂停、重试、清空重建。详见 `release-0.4.0.md`。

默认关闭以避免未经确认的额外调用；启用保存后自动运行。仅处理当前打开的会话，退出软件不运行。

- 纯逻辑测试 53 项：52 通过，1 项真实卡片测试为显式 opt-in，未提供私人卡片而跳过。

- UI fixture 回归：`test:memory`、`test:ui`、`test:studio`、`test:history`、`chat-controls.smoke.mjs`。
- 新增长历史验证：200 条消息、界面只显示 20 条时所有历史仍到达捕获的模型请求；原文保存、显示设置跨重载、加载/收起、滚动锚点、分支隔离、保存失败重试、不重复回复。
- 设置回归：显示条数和模型近期原文分别保存；非有限值、分数、越界值安全规范化，老设置兼容迁移。
- `pnpm install --frozen-lockfile`、TypeScript/Vite 构建、`cargo check --locked`、Tauri Windows x64 EXE/NSIS/MSI 构建。
- `pnpm audit --prod` 本次未报告已知漏洞；这不是完整安全审计，也不覆盖任意远程角色脚本。
- Oxlint 返回成功，但保留现有 React hooks/ref 等警告；Vite 仍有大分块体积警告，不宣称零警告。

这些回归使用隔离测试夹具和本地模拟服务，不读写私人卡片，不自动使用用户真实 Key 扣费；不代表已安装实机、所有模型或任意第三方卡片均验证通过。

## 下载、升级与校验

Windows x64 发布附件：

- `ComfySilly.exe`：直接运行，仍使用标准应用数据目录，并非数据隔离型便携包。
- `ComfySilly_0.4.1_x64-setup.exe`：NSIS 安装程序。
- `ComfySilly_0.4.1_x64_en-US.msi`：MSI 安装程序。
- `SHA256SUMS.txt`：上述二进制文件的 SHA-256。
- `release-notes.md`：本说明。

关闭旧实例再升级，先备份 `%APPDATA%/ComfySilly`。数据目录和应用标识不变。版本号可在窗口标题与「设置 → 数据与关于」核对。

## 已知限制

这是早期公开版本，不代表完整 SillyTavern 生态兼容。EJS、任意 DOM 插件、QuickReply、TTS、生图、通用 DAG 执行和完整世界书扫描策略尚有未实现部分。摘要是有损的，模型上下文按字符估算而非精确 tokenizer；不保证永不遗忘。远程前端资源可用性由其服务控制。当前安装包未签名，无自动升级器。第三方脚本的信任和隐私风险见根目录 `SECURITY.md`。
