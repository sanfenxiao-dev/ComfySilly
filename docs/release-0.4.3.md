# ComfySilly 0.4.3 — 正则分节点导入、可收起聊天工具栏与画布优化

本版包含此前仅本地交付的 0.4.2 画布删除修复。

## 正则：导入目标与执行顺序明确可见

- 每个正则节点有「导入文件」及上传按钮，打开时自动选中该节点；顶部「导入正则」支持选择已有目标或新建节点。
- 支持单条规则对象、规则数组及常见 JSON 包装格式，可一次选择多个文件，也可多次选择追加到待导入队列。
- 导入前可上移、下移或移除文件。按照确认时队列顺序追加，每个文件内部保留原始规则顺序，不覆盖目标节点已有规则。
- 默认保留重复规则；需要时勾选「跳过目标节点中完全相同的规则」。不会跨节点去重，避免不同节点的有意处理被吞掉。
- 保留原始规则 ID、参数、开关与未知字段；空表达式的标题/分隔条目原样保留但不执行。节点显示来源文件名。
- 正则节点间连线参与实际规则排序：先按连线的稳定拓扑顺序排列节点，再按各节点内部的规则顺序执行。无依赖关系时保留已保存的节点顺序；节点编号显示当前执行位置。
- 显示美化和发送侧规则沿用各规则的 placement、promptOnly、markdownOnly、深度等条件，不因分节点而绕过条件。
- 提示词节点的连线可调整实际提示词顺序；其余非正则节点的通用 DAG 执行仍未实现，不把示意连线伪装成完整执行器。

## 聊天阅读

- 对话顶部工具栏支持收起为一条紧凑栏，保留角色名、当前预设和展开入口；展开恢复预设切换、世界书、记忆、历史与新对话等操作。
- 收起偏好保存在本机，重启/重新进入对话继续生效。工具栏占据正常布局空间，不以浮层覆盖正文。

## 画布与性能

- 预设画布原本已在离开预设页时卸载，保留编辑数据不等于后台渲染节点。本版补充了切换至聊天/世界书后不存在 ReactFlow DOM 的回归检查。
- 分离节点语义变化与选择、尺寸测量、拖动位置变化。后者不再触发完整预设序列化，不反复使聊天正则与提示词缓存失效；保存和条目重新编排时再取最新完整图。
- 600 提示词节点 fixture 验证：真实拖动时完整画布序列化次数为 0；切换页面后画布卸载，聊天输入不产生画布序列化。该测试不代表所有机器、远程卡片脚本都不存在卡顿。

## 包含 0.4.2 删除修复

- 右键节点/连线删除，或选中后按 Delete / Backspace，或使用左下角删除按钮；Ctrl 支持多选。
- 删除前确认，删除后可撤销一次。提示词删除同步左侧列表、顺序与关联连线，保存后切换预设不会复活。
- 输入框与弹窗中不误触画布键盘删除。保存失败明确提示，不报假成功。
- 持久化节点位置、自建节点、连线以及内置节点删除状态；修复多个正则节点编辑目标错误。

## 回归与安全边界

- 60 项 JS 测试：常规公开运行 58 通过、2 项私有内容测试 opt-in 跳过；本机启用用户指定的正则只读测试后 59 通过、1 项真实角色卡测试跳过。
- 对指定的两个本地 JSON 只读验证，共 44 + 1 条，逐条保留原始字段与内部顺序；UI 完成目标选择、队列调整和导入保存验证。私人文件未加入源码或发布附件。
- Rust 15 项测试及 TypeScript/Vite 构建通过。付费模型真实调用入口未启用；没有自动使用用户 Key。
- UI 回归覆盖画布删除、正则导入/连线、600 节点页切换、聊天工具栏、书架/世界书/设置、聊天分支、显示窗口、自动记忆和沙盒交互。
- 运行库使用已安装 Zod 的 v4 入口，补齐 prefault/loose 等接口兼容；不放开 iframe 的 allow-same-origin，不暴露真实宿主 DOM。
- 复杂卡片 MVU、作者全局浮动 UI、EJS 与任意酒馆助手插件仍有兼容边界，本版不宣称所有卡片完整可用。保留现有 Vite 大分块和 lint 警告；未签名、无自动升级器。

## 下载与升级

- `ComfySilly.exe`：直接运行版，仍使用标准应用数据目录，不是数据隔离型便携包。
- `ComfySilly_0.4.3_x64-setup.exe`：Windows x64 NSIS 安装包。
- `ComfySilly_0.4.3_x64_en-US.msi`：MSI 安装包。
- `SHA256SUMS.txt`、`release-notes.md`：校验清单与本说明。

关闭旧实例再升级，先备份 `%APPDATA%/ComfySilly`。不更改应用标识或数据目录。窗口标题和「设置 → 数据与关于」均应显示 **0.4.3**；启动无 CMD 窗口。
