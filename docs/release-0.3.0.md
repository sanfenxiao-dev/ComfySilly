## 仍有边界

- 这不是“全部酒馆插件完美兼容”的正式商业成品。EJS、任意酒馆 DOM 插件、QuickReply、TTS、生图与通用 DAG 引擎仍未完整实现。
- 世界书并非酒馆所有高级扫描/分组/概率策略的完整复刻。保存原字段与执行其语义是两件不同的事。
- 历史变量快照不能倒推旧记录未保存的状态；第三方服务、全局/脚本状态与脚本副作用不保证可回滚。
- 导出的对话 JSON 暂无导入入口，不是全库备份；需要全库备份时请备份本机应用数据目录。
- 安装包未做 Authenticode 代码签名，无自动更新服务；依赖已安装的 Windows WebView2（安装程序可处理运行环境）。没有进行跨多台 Windows 的安装/升级矩阵测试。
