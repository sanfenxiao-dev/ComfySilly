# 0.4.2 本地修复包

## 画布删除与保存

- 右键节点选择「删除此节点」，右键连线选择「删除此连线」。
- 选中节点或连线后可按 Delete / Backspace，也可使用画布左下方删除按钮。
- 删除前需要确认，可取消；删除后提供一次撤销。
- 删除提示词时同步移除左侧条目、提示词顺序记录与相关连线；其余条目重新编号。
- 保存完整画布元数据，包括位置、自建节点、连线和已删除内置节点，避免切换预设后复活。
- 输入框编辑与弹窗中不触发画布键盘删除；保存失败明确提示，不再报假成功。

## 同批画布修复

- 提示词节点可手动连接，连接操作同步实际条目顺序。
- 导入单条或多条酒馆正则 JSON，检查格式与表达式、跳过重复规则，保存回预设。
- 修复自建正则节点编辑时误更新默认节点的问题。
- 非提示词的通用流程连线目前是可保存的编辑关系，不代表已经实现通用 DAG 执行。

## 验证范围

使用独立 fixture 验证删除、撤销、输入保护、切换后持久化和保存失败，不修改真实角色卡、聊天、预设或 API 配置，不调用付费模型。

本修复包不等同于完整支持所有酒馆助手插件；复杂角色卡的 MVU、浮动 UI 与外部脚本兼容仍需单独验证。
