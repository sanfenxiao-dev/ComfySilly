# ComfySilly 0.3.1 — 对话与角色前端修复

日期：2026-10-18。

## 使用变化

- 对话顶部显示当前预设，可直接切换；下一次请求使用选中的预设。所选预设和每个预设的本机生成参数覆盖会保留。
- 同一角色卡信任后，切换会话或重新进入无需重复启用；停用也会记住。开场或脚本内容发生变化时重新确认。旧版按内容指纹保存的信任记录仍可读取。
- 修复只有经过显示正则才产生 HTML 的角色卡没有信任入口的问题。判断与消息实际渲染使用同一套显示规则。
- 新前端使用当前会话快照构造初始文档，启动握手补发最新数据，修复作者页面首次读取当前消息为空而留下空白正文的问题。
- 前端组件按 HTML 块保持稳定身份，脚本增加或删除周围文本时，不会销毁内容未变的 iframe 及其中的表单、选项卡状态。
- 卡片内鼠标移动、点击、键盘及滚动会短暂暂停宿主自动追底，避免前端调整高度或后台写入时把用户正在点击的按钮移走。
- `retrieveDisplayedMessage` 返回 jQuery 对象，限当前消息 iframe 自身 DOM；后台或其他消息返回空集合，不开放跨 iframe 或宿主 DOM。
- 修复导入预设回复预留大于上下文造成输入预算异常的问题。只修正本次有效请求参数，保留原预设。
- 对话输入超预算时，可在本次请求中省略较早历史；完整本地消息不删除。预设中的 user/assistant 提示词、系统设定及最新一轮对话不参与裁剪。仍然超预算会提示调整参数，避免把无效请求交给服务端。
- 历史省略会在聊天状态和实际提示词预览中说明，Token 数仍为字符估算。

## 验证

- 单元测试：指定本地真实卡后 41 项全部通过；默认运行时 40 项通过，跳过需要指定角色卡的只读测试。
- Rust 后端：13 项通过；未启用真实外网模型消耗测试。
- 聊天控制回归：预设切换影响实际请求，参数与信任持久化，停用，脚本更新重新确认，正则前端按钮点击，新生成前端同步读取自身消息。
- 独立快照夹具：父级没有广播时，新文档仍能同步读取最新消息；消息 DOM 接口返回当前 frame 内的 jQuery 对象。
- 交互运行环境回归：消息/变量保存、真实 iframe 按钮、后台跨 frame 事件、流式生成生命周期与权限隔离。
- 历史回归：200 条消息的限量渲染、加载更早记录时的滚动锚点、历史隔离、保存失败重试及防止重复生成均通过。
- 工作室回归：书架、世界书开关/删除/撤销、用户身份、设置分类、历史编辑分支、重新生成版本与导出均通过。
- 本地真实角色卡只读副本：作者远程脚本和页面实际运行；开局表单写变量、按钮触发生成、回复保存、正文显示在作者页面、原生鼠标进入后点击“世界”切换成功。最终通过记录中页面异常和失败网络请求均为 0。
- 追加修复：未加围栏的 `<details>/<button>/<div>` 等交互片段会按 HTML 挂载，不再被 Markdown 转义成源码文本；同一网络错误在卡片页面中去重；流式回复在最终消息提交前先收起临时副本，避免视觉上出现两段相同回复。
- 生成由测试 IPC 返回固定回复，没有调用用户模型，也没有使用用户密钥或消费模型额度。真实卡片、对话副本、第三方脚本缓存和测试截图不提交到 Git。
- Windows Release 构建成功，包含独立 EXE、NSIS 与 MSI。PE GUI 子系统为 2，不使用 CMD 启动。
- Lint 退出码为 0，仍有已有 Hook/未使用变量等警告；构建有大分包体积提示，未宣称全部消除。

## 已知边界与后续验收

- 这是兼容性修复试用版，不是任意酒馆卡/插件的完整兼容认证。EJS 提示词模板、跨消息 DOM 操作等边界仍见 0.3.0 说明。
- Edge 无头自动化中，滚动使 iframe 进入视口后立刻点击仍复现过未命中。原生鼠标移入、等待布局稳定 150ms 后点击可通过；自动追底暂停已覆盖回归，但不能据此声称所有点击时序都已修复。尚未完成该路径的桌面 WebView2 手工验收。
- 某些作者服务端会拒绝沙盒 iframe 的 `Origin: null` 请求并返回 `Origin header is not a valid URL`。本轮已避免同一错误重复刷屏，但未把第三方网络请求统一代理到宿主；这类卡片仍可能需要后续的安全代理/兼容层。
- 独立诊断中曾加载出地图、世界数据与三张角色立绘；最终首次开局回归只确认正文和世界选项卡，附近角色/时间仍可能未刷新，未把立绘弹窗或完整世界状态同步记为通过。作者后台初始化、消息事件和前端刷新时序需要继续收敛。
- 字符估算不是模型真实 tokenizer；用户仍需按实际模型设置上下文上限。
- 不包含代码签名、自动更新或 GitHub Release 上传。
